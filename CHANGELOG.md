# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2026-07-31

### Added

- Responsive custom LuCI dashboard with live and monthly metrics
- Smart Connect-style main Wi-Fi and guest Wi-Fi page
- WPA2/WPA3 Mixed and WPA2 Personal selector
- Dedicated WAN Setup page with DHCP, Static IP, PPPoE, DNS, MTU, and MAC mode
- Guest network, DHCP, firewall isolation, and bridge isolation
- Automatic LAN-device discovery and DHCP reservation
- Per-device Internet pause, priority, and upload/download limits
- CAKE SQM with WAN interface synchronization
- Adblock configuration, disabled by default
- Watchcat WAN recovery and delayed reboot fallback
- Monthly `nlbwmon` accounting with hourly persistent commits
- Upgrade persistence and one-time migration markers
- GitHub-safe generic SSIDs and passwords
- Hardware MAC default with optional clone-MAC page
